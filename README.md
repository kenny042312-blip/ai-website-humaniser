# AI Website Humaniser 1.0

Codex skill for designing or revising websites so their content, structure and visual choices fit a real audience and task instead of defaulting to a generic template.

**Version:** 1.0.0 (`v1.0.0`)

The skill uses evidence carefully: the source website-directory study measured URL structure and initial server HTML, not rendered visual design. Its visual suggestions are presented as experiments, not as proven signs of human authorship.

## Install

Copy this folder into `~/.codex/skills/ai-website-humaniser` or `$CODEX_HOME/skills/ai-website-humaniser`, then invoke `$ai-website-humaniser` or describe the website you want to improve.

## Contents

- `SKILL.md` — skill entrypoint and design workflow.
- `references/research-basis.md` — study findings, denominator corrections and evidence limits.
- `agents/openai.yaml` — Codex skill-list metadata.
